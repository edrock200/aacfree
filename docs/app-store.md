# Publishing AACFree on the Apple App Store: owner checklist

The iPhone/iPad app is the same web app inside a native shell (Capacitor, `ios/`). Compared with the web app in Safari it adds:
- **Boards are never wiped.** Safari can delete a website's data after about 7 days without a visit; an app's data stays.
- **Automatic backups** to the app's folder in the Files app, plus an optional copy in iCloud Drive, Google Drive, OneDrive or Dropbox (`AACFreeFiles`, Swift, in `ios/App/App/AACFreePlugins.swift`), and automatic sync through one shared file.
- The device's own voices through the native speech engine, and keep-screen-awake (`AACFreeScreen`).

| What | Where |
|---|---|
| Bundle id | **`com.aacappfree.app`** (can't change after the first upload) |
| Minimum iOS | 16.4 (needed by on-device text recognition) |
| Native project | `ios/App/App.xcodeproj` (Swift Package Manager; no CocoaPods) |
| Icon, splash | generated by `node scripts/make-icons.mjs` |
| Store listing | `fastlane/apple/`: screenshots, creative assets and the text in four languages (see its README) |
| Permission texts | `ios/App/App/Info.plist` (English) and `ios/App/App/{es,fr,pt}.lproj/InfoPlist.strings` |
| Build check | `.github/workflows/ios.yml` builds for the Simulator on every pull request |
| Privacy policy | `https://aacappfree.com/privacy.html` |

---

## 1. Apple Developer Program

1. Enrol at <https://developer.apple.com/programs/enroll/> with the Apple Account that should own AACFree long-term: **US$99 a year**. As an individual it takes a day or two; as an organisation you need a D-U-N-S number.
2. Non-profits, accredited schools and government bodies can ask for a **fee waiver** (<https://developer.apple.com/support/membership-fee-waiver/>).
3. Note your **Team ID** (Membership details), for example `ABCDE12345`.

## 2. Create the app in App Store Connect

<https://appstoreconnect.apple.com> → **Apps → + → New App**:
- Platform: **iOS**. Name: **AACFree – Talk with pictures** (30 characters max). Primary language: English (U.S.).
- Bundle ID: **com.aacappfree.app**. If it isn't in the list, register it first under Certificates, Identifiers & Profiles → Identifiers (no extra capabilities are needed).
- SKU: `aacfree`. User access: Full access.

## 3. Let GitHub build and upload (no Mac needed)

1. App Store Connect → **Users and Access → Integrations → App Store Connect API → Team Keys → +**. Name it `GitHub`, access **Admin** (Admin is needed so Xcode can create the distribution certificate and profile in the cloud). Download the `.p8` file (only once) and note the **Key ID** and the **Issuer ID** shown above the list.
2. GitHub → the repo → **Settings → Secrets and variables → Actions → New repository secret**, four times:
   - `APPLE_TEAM_ID`: your Team ID
   - `ASC_KEY_ID`: the Key ID
   - `ASC_ISSUER_ID`: the Issuer ID
   - `ASC_KEY_P8`: the whole contents of the `.p8` file, including the `BEGIN`/`END` lines
3. **Actions → iOS app → Run workflow** on `main`, with **upload** ticked. It builds, signs and uploads the version in `package.json`. The build number is the version code plus the run number (0.8.0 run 12 → `800.12`), so every upload is unique.
4. After 10–30 minutes the build appears in App Store Connect → **TestFlight**.

With a Mac instead: `npm ci && npm run build && npx cap sync ios && npx cap open ios`, choose your team under Signing & Capabilities, then **Product → Archive → Distribute App**.

## 4. Test with TestFlight first

1. **TestFlight → Internal testing**: add yourself and family (up to 100 people in your team). Install the **TestFlight** app on an iPad and an iPhone.
2. Check on a real device:
   - speech with the device voices, and a recorded voice on a button
   - taking a photo for a button; importing a board from a screenshot
   - head and eye pointer (camera permission appears the first time)
   - Settings → Backup → Automatic backups: **Back up now**, then the file appears in the **Files** app → On My iPad → AACFree
   - **Add a cloud copy…** to iCloud Drive, then restore from it
   - sync with another device through one shared file
   - Guided Access (Settings → Accessibility) keeps the person in the app
3. **External testing** (people outside your team, up to 10,000) needs a short Beta App Review the first time.

## 5. App information and pricing

- **Category:** Primary **Education**; secondary **Medical** is optional. Don't choose the **Kids** category: it requires a parental gate in front of every outside link and forbids sending anything to third parties (the optional ARASAAC picture search would need rework).
- **Price:** Free, all countries. It must stay free with no in-app purchases or ads: the ARASAAC pictograms are non-commercial (CC BY-NC-SA).
- **Content rights:** "Yes, it contains third-party content, and I have the rights": ARASAAC pictograms (CC BY-NC-SA 4.0, credited in the app) and the Atkinson Hyperlegible font (SIL OFL).
- **Age rating questionnaire:** None for every item; no user-generated content shared with others, no web browsing, no messaging. Expected rating **4+**.
- **Medical device:** if asked, AACFree is not a regulated medical device. Use the same statement as Play:
  > AACFree is a communication tool (augmentative and alternative communication). It is not a medical device. It does not diagnose, treat, cure, monitor or prevent any disease or condition, and it makes no medical claims.

## 6. App Privacy ("nutrition label")

**Data collection: "No, we do not collect data from this app."**
- Boards, photos, voice recordings, settings, the optional usage log, backups and sync files stay on the device, or go where the family chooses (Files, iCloud Drive, another app). Apple's definition of collection is data sent off the device to the developer or a partner; none is.
- The camera (photos, head/eye pointer) and microphone are processed on the device only.
- The optional online picture search sends the typed search words straight to ARASAAC with no identifiers and keeps no history. If you want to be extra careful, declare instead *Search History → App Functionality, not linked to identity, not used for tracking*.
- Tracking: **No.**

## 7. The version page

- **Screenshots:** required for **iPhone 6.9"** (1320 × 2868 portrait or 2868 × 1320 landscape) and **iPad 13"** (2064 × 2752 or 2752 × 2064). Ready-made ones are in **`fastlane/apple/screenshots/en-US/`** (`iPhone_*.png` and `iPad_*.png`). Regenerate them with `IOS=1 node scripts/store-screenshots.cjs <preview url>` (see the script's header).
- **Name, subtitle, promotional text, description, keywords:** ready in `fastlane/apple/metadata/<language>/` for English, Spanish, French and Portuguese (see `fastlane/apple/README.md`).
- **Support URL:** `https://aacappfree.com/guide/`. **Marketing URL:** `https://aacappfree.com`. **Privacy policy URL:** `https://aacappfree.com/privacy.html`.
- **Copyright:** `2026 AACFree contributors`.
- **App Review information:** no sign-in needed. Notes:
  > No account or login. Settings and editing are behind the Settings button in the bottom bar: press and hold it for 2 seconds. No PIN is set by default. Everything works offline. The camera is used for button photos and the optional head/eye pointer; the microphone for recording a voice for a button.
- **Export compliance:** already answered in `Info.plist` (`ITSAppUsesNonExemptEncryption` = NO): the app only uses the operating system's encryption to protect the family's own backup and sync files, which is exempt.

## 8. Things Apple reviewers sometimes raise

- **4.2 Minimum functionality ("just a website"):** if it comes up, reply that the app works fully offline, keeps boards on the device for good (unlike Safari), uses the device's speech engine, camera and microphone, and saves automatic backups to the Files app. AAC apps of this kind are established in the store.
- **Permissions:** every permission is asked only when a grown-up turns on the feature, and each has an explanation in four languages.

## 9. Licence: AGPL and the App Store

The app's code is AGPL-3.0. The Free Software Foundation considers the App Store's terms incompatible with the GPL family of licences, and in 2011 VLC was removed after one of its contributors objected.
- You hold the copyright to your own code, so you can publish it.
- If other people contributed code (for example through pull requests), ask each of them for written permission, or add an **App Store exception** to the licence before submitting, for example in `NOTICE`:
  > As an additional permission under section 7 of the GNU AGPL, the copyright holders of AACFree give permission to distribute this program through app stores whose terms add restrictions on use or redistribution (such as the Apple App Store), provided the complete corresponding source code remains available under the AGPL.
- The libraries AACFree uses are MIT, Apache-2.0 or OFL, which are fine.

## 10. Releasing an update

1. Bump `package.json` and release as usual (see the `release` skill).
2. **Actions → iOS app → Run workflow** on `main` with **upload**.
3. App Store Connect → the app → **+ Version**, pick the new build, paste the CHANGELOG section into "What's New", **Submit for Review**.
