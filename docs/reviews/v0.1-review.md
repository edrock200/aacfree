# v0.1 review → v0.2 changes

Two independent review threads ran in parallel on v0.1:
- **Thread A** looked at product, UX and accessibility by driving the real app at phone and tablet sizes.
- **Thread B** looked at engineering, data integrity, Android and PWA behaviour, performance and security.

Below is what each thread found and what v0.2 did about it.

## Thread A: product, UX, accessibility

| # | Finding | v0.2 |
|---|---|---|
| 1 | On phones, Grown-ups couldn't be re-locked and its tabs were cut off | Tabs wrap into a grid and Lock stays in the nav bar. Grown-ups auto-relocks after 5 idle minutes or more than 1 minute in the background. Locking returns to Home. |
| 2 | Tools forgot their state; the timer stopped | The timer, First/Then and Choices live in the store. The timer keeps running and alarming on every screen, with a countdown chip and a +1 min button. |
| 3 | Find word pointed at nothing for hidden words and dead-ended on a miss | Hidden words are temporarily shown and labelled "hidden for now", with Reveal when unlocked. A miss offers Say it, Put in message, and Add to a board. |
| 4 | No quick hide/reveal | Show/Hide mode in edit mode: one tap masks or reveals a word. "Reveal 5 more". |
| 5 | Nowhere to add a word | "+ Word" dialog with a suggested picture. If the board is full it appends a row, so nothing moves. |
| 6 | Long scrolling folders; thin phone core | Fixed pages with constant Previous/Next buttons. New 5×6 "Phone core" layout, now the default on phones. |
| 7 | Keyboard gaps | Physical/Bluetooth keyboard typing, auto-capitalised "I", and a built-in next-word table so prediction works with learning off. |
| 8 | Partner modelling inflated the insights | "Model" toggle (shown when logging or learning is on). Modelled taps are tagged, excluded from stats and from learning, and exported as "partner". |
| 9 | Thin schedule | Steps can be edited (picture, label, minutes). Now can start a timer for the step. Duplicate schedule. Compact Now/Next. |
| 10 | Forgotten PIN meant wiping the app | "Forgot PIN?" asks for a 10-second hold plus a typed sentence, then removes only the PIN. |
| 11 | English only | **Deferred.** Needs a decision on which languages (see README roadmap). |
| 12 | Dark/contrast themes hard to read | Light plate behind pictograms; minimum label size on phones. |
| 13 | No pronunciation fixes | Pronunciations list (word → say as), applied to everything spoken. |
| 14 | Navigation surprises | Tools inside a tool returns to the Tools menu. Lock returns Home. Choices remember offer mode. |
| 15 | Backup is manual | **Partly done.** The backup nudge and storage usage are shown. Scheduled auto-export to a cloud folder is deferred. |

## Thread B: engineering

| # | Finding | v0.2 |
|---|---|---|
| 1 | A second tab overwrote newer data | Revision-checked saves plus BroadcastChannel. Only unsaved changes are flushed. A conflict reloads the other window's data instead of overwriting it. |
| 2 | A malformed backup bricked the app | `src/lib/validate.ts` repairs or rejects every load and restore. Restoring asks for confirmation. Error boundary with "Restore last automatic backup" and "Save my data". |
| 3 | XSS in the print view | Hex-only colours everywhere, numeric grid sizes, full escaping, and a CSP in the print page. |
| 4 | CI could publish a debug-signed release; versionCode was hardcoded | Release tags fail without signing secrets. The release job is separate (least privilege). Version comes from package.json (versionCode 200 = 0.2.0). |
| 5 | Save failures were invisible | Retries, then a persistent red banner with "Save a backup file now". Storage usage is shown. |
| 6 | Android TTS failed silently or used the wrong voice | Voice is stored by name. Falls back to the device language. Failure shows a toast with "Install voices". |
| 7 | A service-worker update reloaded mid-sentence | Prompt mode; the update applies only when idle and hidden. |
| 8 | Assets were never garbage-collected | Snapshot-aware GC with a 1-day grace period. ARASAAC downloads are deduplicated, and bundled ids are reused. |
| 9 | Android couldn't re-import .obz; big backups risked running out of memory | The picker accepts any file type and validates the content. Backups are written in chunks. |
| 10 | OBF import not hardened | Size and grid caps, no arbitrary remote fetches, boards validated. |
| 11 | Every tap re-rendered all 72 buttons | Memoised screen and grid with stable callbacks. Shallow updates for history and settings. |
| 12 | Library deletions had no undo | Snapshot plus an Undo toast. Orphaned additions show under "My extra symbols". |
| 13 | Profile delete left the undo stack and usage log behind | Both are cleared. |
| 14 | Android Auto Backup | Kept on, so it acts as a safety net to the family's own Google account. Documented in the README privacy section. |
| 15 | The daily snapshot blocked startup | Now runs in the background. |
| 16 | Test gaps | New validation/migration/pronunciation unit tests (35 total). e2e covers the v0.2 features (46 checks). The CI workflow runs the e2e. |
